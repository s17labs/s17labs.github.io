# Privacy policy — s17 Labs

No accounts. No tracking. No analytics. This site is a static bundle of
files — there is nothing here that can follow you.

This document is the canonical policy text. It is mirrored on
<https://s17labs.github.io/privacy/>.

## Your data stays yours

Everything you type, paste, or drop into s17 Labs Tools is processed
locally in your browser and never uploaded anywhere. Close the tab and
it's gone — nothing is stored on a server because there is no server.

## Network requests

The pages themselves make zero requests of their own: no analytics
beacons, no cookies, no fingerprinting. Two exceptions, both visible
and in your control:

| When | What leaves your device |
|---|---|
| Icon Maker emoji | Fetching a Noto/Twemoji glyph requests that one SVG file from the jsDelivr CDN. Nothing else is sent. |
| Hosting | GitHub Pages serves these static files and, like any host, may keep routine anonymized server logs. |
